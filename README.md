# CHAOS CHESS

A custom 16×16 chess-variant prototype.

## Current prototype
- 16×16 battlefield with the starting armies centered on the board.
- Click-to-select and click-to-move for standard chess pieces.
- Standard piece images are loaded from the Chess.com Neo piece theme CDN, with Unicode fallbacks if an image fails.
- Basic movement for pawns, rooks, knights, bishops, queens, and kings.
- Prototype fusion controls for Pawn Overlord and the King + Queen bonus-pawn rule.

## Important
This is an early playable foundation, not the complete rules engine. Giant-piece movement, multi-square collision, special attacks, JJK/Undertale character drops, multiplayer, and full victory logic still need implementation and testing. The Chess.com piece art is externally hosted; use is subject to the asset provider's terms. If you have a permitted local asset pack, it can be vendored into the project later.

## Run
Open `index.html` in a browser or enable GitHub Pages for the repository.
